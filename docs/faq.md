# Frequently Asked Questions (FAQ)

## General Questions

### What is Tiny VM Desktop Environment?

Tiny VM Desktop Environment is a lightweight desktop environment designed to run within virtual machines. It is optimized for minimal resource usage while still providing a usable GUI for basic tasks such as file management, terminal access, and VM control.

### What virtualization software do I need?

The environment supports several virtualization solutions, including:
- **QEMU**
- **VirtualBox**
- **KVM**
- **Docker (for containerized environments)**

## Installation Questions

### How do I install Tiny VM Desktop Environment?

You can follow the installation guide in [setup.md](setup.md) to get started. Ensure that your system meets the prerequisites, such as Python, QEMU/VirtualBox, and pip.

### I'm getting an error: "Virtualization not supported."

This error means that your system's BIOS/UEFI has virtualization disabled or does not support it. You will need to enable virtualization in the BIOS/UEFI settings or use a system that supports virtualization.

## Usage Questions

### How do I create a new virtual machine?

You can create a new VM by opening the **VM Manager** from the taskbar, then selecting "New VM." You can specify the VM's settings, such as memory and CPU allocation, before creating it.
